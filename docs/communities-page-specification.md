# Communities Page Specification

## Objective

Create a premium corporate Communities page for **SMB Real Estate Brokers L.LC**.

This page replaces the traditional Projects listing page. Its purpose is to help visitors explore Dubai real estate opportunities by community, then view the available projects within each location.

The page must remain consistent with the Homepage, About, Services, Developers, Contact, and Project Landing Pages.

Do not create an experimental or award-style layout.

---

## Visual Direction

The page should feel:

- Premium
- Elegant
- Modern
- Spacious
- Professional
- Location-focused
- Easy to explore

Avoid:

- Heavy animations
- Complex filters
- Generic property portal styling
- Dense project listings
- Excessive cards
- Autoplay carousels
- Large decorative graphics

Use the SMB brand colors:

- Navy Blue: `#0a2342`
- Golden Yellow: `#f9ba3f`

Use gold sparingly as an accent.

---

# Page Structure

## 1. Inner Page Hero

Include:

- Eyebrow: `Dubai Communities`
- Main heading
- Short supporting paragraph
- Optional breadcrumb
- Supporting Dubai lifestyle or city image

Suggested heading direction:

`Explore Dubai’s Most Sought-After Communities`

The hero must be shorter than the homepage hero.

---

## 2. Communities Introduction

Briefly explain why location and community selection matter.

Focus on:

- Lifestyle
- Property type
- Connectivity
- Amenities
- Investment goals
- Long-term potential

Keep the copy concise.

---

## 3. Featured Communities

Display 4–6 large premium community cards.

Suggested temporary communities:

- Downtown Dubai
- Dubai Marina
- Business Bay
- Dubai Hills Estate
- Palm Jumeirah
- Dubai Creek Harbour

Each card includes:

- Community image
- Community name
- Short positioning statement
- Available property types
- Optional project count if verified
- CTA: `Explore Community`

Do not list individual projects inside these cards.

Do not display unverified prices or statistics.

---

## 4. Browse All Communities

Display all available communities in a clean responsive grid.

Each item includes:

- Image or thumbnail
- Community name
- Short description
- Main property categories
- CTA

The grid must be easy to scan, responsive, CMS-friendly, and suitable for future expansion.

Do not turn the page into a property portal.

---

## 5. Explore by Lifestyle

Suggested categories:

- Waterfront Living
- Family Communities
- City Living
- Luxury Destinations
- Investment Areas
- Emerging Communities

Each item should link to a relevant filtered view or community page when available.

Do not add complex filtering logic during the static preview phase.

---

## 6. Choosing the Right Community

Explain how SMB helps visitors compare locations.

Focus on:

- Understanding client goals
- Comparing lifestyle and investment needs
- Evaluating connectivity
- Reviewing property options
- Matching communities to budget
- Supporting the final decision

Use a clean split layout or structured list.

---

## 7. Communities Map

Include:

- Simplified Dubai map, map image, or temporary placeholder
- Markers for featured communities
- Optional links to community pages

The map must support the page, not dominate it.

Do not add a complex interactive map unless requested later.

---

## 8. Featured Opportunities

Display a small curated selection of 3–4 project cards.

Each card may include:

- Project image
- Project name
- Community
- Developer
- Property type
- Starting price only if verified
- CTA: `View Project`

Keep this section secondary to the communities directory.

Do not display a large project archive here.

---

## 9. Frequently Asked Questions

Display 5–6 questions related to selecting a Dubai community.

Use an accessible accordion.

Suggested topics:

- Family-friendly communities
- Waterfront communities
- Comparing locations
- Ready and off-plan availability
- Investment-focused areas
- Booking a consultation

Keep answers concise.

---

## 10. Final CTA

Include:

- Strong headline
- Short supporting text
- Contact button
- WhatsApp button

Suggested direction:

`Not Sure Which Dubai Community Fits Your Goals?`

---

## 11. Footer

Reuse the global corporate footer.

# Content Model

Each community should be structured for future CMS management.

Recommended fields:

- Community name
- Slug
- Short description
- Full introduction
- Featured image
- Gallery
- Location
- Lifestyle categories
- Property types
- Amenities
- Connectivity
- Nearby destinations
- Available projects
- SEO title
- SEO description

The listing page does not need to display all fields.

---

# General Rules

- Keep the page consistent with the existing SMB website.
- Reuse the same header, footer, typography, spacing, buttons, cards, and design tokens.
- Maintain generous spacing.
- Keep text concise and readable.
- Use subtle background changes between sections.
- Keep cards simple and premium.
- Avoid excessive borders and shadows.
- Use subtle hover and reveal effects.
- Respect `prefers-reduced-motion`.
- Ensure desktop, tablet, and mobile layouts are complete.
- Do not add complex live filtering in the static preview.
- Do not add unverifiable prices, statistics, rankings, or project counts.
- Do not invent community facts.
- Do not make this page a duplicate of the Developers page.
- Do not make this page a duplicate of a Projects archive.
- Keep the structure CMS-friendly and scalable.

The final page must clearly communicate:

- Which Dubai communities visitors can explore
- How communities differ by lifestyle and property type
- How SMB helps clients select the right location
- How visitors can access projects within each community
