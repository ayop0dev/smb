# Photography Style

Preferred photography style:

- Real photography
- Bright natural lighting
- High-resolution imagery
- Luxury residential architecture
- Modern interiors
- Lifestyle photography
- Dubai landmarks where appropriate

Avoid:

- Low-quality renders
- Over-processed HDR
- Generic stock imagery where possible

---

# Illustration Style

Illustrations should be:

- Minimal
- Modern
- Clean
- Geometric

Use illustrations only when photography is unavailable.

---

# Iconography

Preferred icon style:

- Outline Icons
- Rounded Corners
- Minimal Detail
- Consistent Stroke Width

---

# UI Style

The interface should follow:

- Spacious layouts
- Large imagery
- Strong typography hierarchy
- Clean sections
- Premium white space
- Minimal visual noise
