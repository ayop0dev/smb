# Developers Page Specification

## Objective

Create a premium corporate Developers page for **SMB Real Estate Brokers L.LC**.

The page introduces the leading real estate developers that SMB works with and helps visitors explore projects by developer.

This page is not a Projects page.

It should build confidence in the quality of the developers while directing visitors to dedicated developer and project pages.

---

## Visual Direction

The page should feel:

- Premium
- Professional
- Elegant
- Modern
- Spacious
- Trustworthy

Avoid heavy animations, decorative graphics, dense layouts, or generic logo walls.

Reuse the existing SMB design system.

---

# Page Structure

## 1. Inner Hero

- Eyebrow: Developers
- Main heading
- Short supporting paragraph
- Lifestyle image
- Optional breadcrumb

---

## 2. Introduction

Briefly explain that SMB works with carefully selected Dubai developers known for quality communities, strong reputations, and long-term investment value.

---

## 3. Featured Developers

Display premium cards for:

- Emaar
- Aldar
- Nakheel
- Meraas

Each card includes:

- Logo or placeholder
- Developer name
- Short description
- Available projects (placeholder if needed)
- View Developer CTA

---

## 4. Why These Developers

Explain the selection criteria.

Topics:

- Proven reputation
- Build quality
- Prime locations
- Investment potential
- Strong communities
- Long-term value

---

## 5. Browse by Developer

Responsive grid of all developers.

Each item includes:

- Logo
- Name
- Short tagline
- View Projects button

Design this section so additional developers can be added easily through the CMS.

---

## 6. How SMB Helps

Explain how SMB helps clients:

- Compare developers
- Match projects to budgets
- Understand payment plans
- Evaluate communities
- Complete the buying journey

Remain objective. Do not promote one developer over another.

---

## 7. FAQ

5–6 questions about developers, off-plan opportunities, choosing the right developer, and consultations.

Use a clean accordion.

---

## 8. Final CTA

- Strong headline
- Supporting text
- Contact button
- WhatsApp button

Suggested direction:

Need Help Choosing the Right Developer?

---

## 9. Footer

Reuse the global footer.

# General Rules

- Reuse the global design system.
- Maintain generous spacing.
- Keep typography elegant.
- Keep cards simple.
- Use subtle hover effects.
- Avoid excessive borders and shadows.
- Respect `prefers-reduced-motion`.
- Fully responsive.
- Do not list projects inside developer cards.
- Do not invent rankings, awards, or statistics.
- Build developer cards to be CMS-friendly for future expansion.

The page must clearly communicate:

- Which developers SMB works with
- Why they are trusted
- How SMB helps clients choose between them
- How visitors can browse projects by developer
